用手机扫码下载

扫码后浏览器会直接开始下载 APK，也可以在手机上打开本页点上面的按钮。

三步装好

  1. 点上面的按钮下载 APK。
  2. 打开下载好的文件，如果系统提示「不允许安装未知应用」，按提示去设置里给浏览器或文件管理器打开这个权限，然后回来重新点一次安装。
  3. 安装完成后打开 App，在设置里点「检查更新」，之后的版本就会自动升级。

第 3 步是关键：装好这一版之后，以后的更新都在 App 里点一下「检查更新」就能完成，不用再回到这个页面。这个页面只负责把第一个安装包交到你手上。

几点说明

  • 只支持 Android，不支持 iOS。
  • 首次安装需要允许「安装未知应用」，这是安卓侧载 APK 的正常提示。
  • 内容来自第三方公开采集接口，App 本身不存储任何视频，也不提供片源。
  • 需要 Android 8.0 及以上。
